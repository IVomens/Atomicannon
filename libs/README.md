# libs/

Jars from other mods used while building and testing. They are not part of this repository (they are not ours to
redistribute); put them here yourself.

| File | Needed for | Where it comes from |
|---|---|---|
| `warforge-26.2.jar` | **Compiling** (optional WarForge claim support) and the claim tests | WarForge Factions 26.2 port |
| `ldlib2-26.2.jar` | Dev/test runs only (WarForge dependency) | LDLib2 for 26.2 |
| `mafglib-26.2.jar` | Dev client runs with `-PwithMafglib` only | mafglib for 26.2 |
| `foxified-classtweaker.jar` | Dev client runs with `-PwithMafglib` only | Foxified ClassTweaker |

HBM's Nuclear Tech Mod (ntm-next) and Crankshaft are downloaded by Gradle automatically.
